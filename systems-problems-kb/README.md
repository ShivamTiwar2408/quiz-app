# Distributed Systems Problems — a field guide

A self-contained reading page covering 27 classic distributed-systems problems across
three tiers (Beginner / Intermediate / Advanced). For each problem: the premise and the
year/era it was named, why it happens, how it's solved, real papers & canonical references,
and useful links.

- **Live:** https://shivamtiwar2408.github.io/quiz-app/systems-problems-kb/
- `index.html` — the reading app (left tier→problem tree, right reading pane, deep-linkable via `#/<problem-id>`).
- `data.json` — all content (the single source of truth the page renders).

Research was verified against primary sources (papers, vendor docs, engineering blogs);
where no formal academic paper exists, that is stated plainly rather than fabricated.
